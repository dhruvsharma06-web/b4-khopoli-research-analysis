# B4 Khopoli – Research & Analysis

Should a luxury 6BHK pool villa in Godrej Hillview, Khopoli be rented long-term or run as a short stay?

This site presents the full study: 192 villas and 42 rentals across Khopoli, Lonavala and Karjat, real market booking data, the KDD approach, the risk analysis, and a marketing plan.

## Pages

- **Home** – 5W1H, the datasets, three locations, the answer
- **Data** – villas, rentals, market and brands, with search, filters and links to every listing
- **Analysis** – every earning option, rent vs night stay by floor, best months, risk
- **Marketing** – 13-point marketing strategy and launch order
- **Approach** – how the data was collected, cleaned, modelled and checked

## Run locally

It is a static site. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Import this repository in Vercel. No build step or settings are needed.
